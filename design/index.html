Salary Conversion & Industry Aliases

Salary bounds in YAML are USD per year. A posting draws a currency and a pay period independently of the industry, so the amount is converted to match before the BaseSalary is built — otherwise the figures would contradict their own labels.

Industry aliases

The seven pre-1.1.0 industry keys resolve to their LinkedIn equivalent through a top-level aliases: block, applied before industry lookup. Aliases are accepted by buildForIndustry but deliberately absent from availableIndustries(). An alias pointing at an unknown industry throws at class initialisation rather than silently falling back.

retail, manufacturing and education need no alias — they are already canonical LinkedIn names.

Usage Examples

// Fully random posting
JobFaker faker = new JobFaker();
JobPosting job = faker.jobPosting().build();

// Industry-targeted
JobPosting site = faker.jobPosting().buildForIndustry("construction");

// Legacy keys still resolve — "technology" is an alias
JobPosting tech = faker.jobPosting().buildForIndustry("technology");

// Seeded — fully reproducible
JobFaker seeded = new JobFaker(new Random(42L));
JobPosting same  = seeded.jobPosting().build(); // always identical

// Inspect reference-data lists (all sourced from YAML)
faker.jobPosting().availableIndustries();      // 20 canonical keys (aliases not listed)
faker.jobPosting().availableEmploymentTypes(); // ["FULL_TIME","PART_TIME","CONTRACTOR","TEMPORARY","INTERN","VOLUNTEER","PER_DIEM"]
faker.jobPosting().availableCurrencies();      // ["USD","EUR","GBP","INR","CAD","AUD","SGD"]
faker.jobPosting().availableSalaryUnits();     // ["HOUR","DAY","WEEK","MONTH","YEAR"]

// Access fields
System.out.println(job.industry());                  // "Technology, Information and Media"
System.out.println(job.title());                     // "Staff Software Engineer"
System.out.println(job.skills());                    // ["Java", "Kubernetes", "AWS"]
System.out.println(job.employmentType());            // "CONTRACTOR"
System.out.println(job.baseSalary().currency());     // "EUR"
System.out.println(job.baseSalary().minValue());     // 8000  — converted to EUR/MONTH
System.out.println(job.baseSalary().unitText());     // "MONTH"
System.out.println(job.jobLocation());               // "Austin, TX" or "Remote"
